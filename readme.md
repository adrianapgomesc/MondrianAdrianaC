# Mondrian Parte A

Para conseguir recriar a composição III do Mondrian com a maior fidelidade possível, coloquei a imagem de referência no illustrator, de forma a conseguir tirar as medidas. Usei como largura os 800px, e apliquei várias regras de três simples, para que a recriação em código ficasse o mais parecida possível à imagem de referência, incluindo as medidas, cores e alinhamentos. Usei o fill para preencher com a cor correta os vários quad. Ao usar o quad, permitiu-me ter uma maior capacidade de perceber como funcionam os eixos, uma vez que tenho de definir 8 parâmetros para cada quad: comprimento, largura, onde começam e onde terminam. Compreender a matemática ajuda a colocar tudo corretamente. Para as limhas pretas, defini um strokeweight e, novamente, defini onde queria que a linha começasse e terminasse, e o seu comprimento ou largura.
